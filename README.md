# Student Dormitory System

Ақпараттық жүйе студенттік жатақхананы басқаруға арналған.

## Мақсаты

Жатақханадағы бөлмелерді, студенттерді және орналастыруды есепке алу.
Свободное место проверяется при заселении студента.
