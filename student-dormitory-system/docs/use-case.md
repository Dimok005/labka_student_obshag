# Use Case диаграммасы

## Акторлар

- Әкімші (Admin)

## Прецеденттер

| Прецедент | Сипаттамасы |
|---|---|
| Бөлме қосу | Әкімші жаңа бөлме мен оның орын санын қосады |
| Студент тіркеу | Әкімші студенттің атын және ID-ін тіркейді |
| Орындастыру | Студентті бос бөлмеге орналастырады |
| Тізімді көру | Бөлмелер мен студенттер тізімін қарайды |

```
Әкімші ---> (Бөлме қосу)
Әкімші ---> (Студент тіркеу)
Әкімші ---> (Орындастыру)
Әкімші ---> (Тізімді көру)
```
