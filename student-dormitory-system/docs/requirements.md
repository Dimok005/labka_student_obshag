# Талаптар (Requirements)

## Функционалдық талаптар

1. Жүйе бөлмелерді қосуға мүмкіндік беруі тиіс.
2. Жүйе студенттерді тіркеуге мүмкіндік беруі тиіс.
3. Жүйе студентті бөлмеге орналастыруы тиіс.
4. Жүйе бөлмелер мен студенттер тізімін көрсетуі тиіс.
5. Жүйе бос орындар санын есептеуі тиіс.

## Функционалдық емес талаптар

- Python 3.10+ нұсқасында жұмыс істеуі.
- Бастапқы код түсінікті және құрылымды болуы.
- Қате өңдеуі болуы (мысалы, бөлме толып кетсе).
